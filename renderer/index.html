机型说明

使用前请确认
  • 小米：需开启「USB 调试（安全设置）」并重启手机，否则只能看画面、不能点击。
  • 一加 / OPPO：点击无反应时，在开发者选项关闭「权限监控」（旧版显示「禁止权限监控」）。
  • 驱动：列表为空时安装厂商 USB 驱动；USB 模式选「传输文件」。
  • 无线：手机与电脑需在同一 Wi-Fi；首次用「无线调试」配对码配对，之后用 IP 直连。
  • 多设备：当前一次投屏一台，停止后可切换到其他手机。
